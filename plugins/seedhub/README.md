# SeedHub 磁力与多网盘

## 插件能力

SeedHub 是 AList-TVBox `1.42.0` raw Python 插件。它提供首页、电影/动漫/剧集分类、分页、搜索、详情和资源分组。

详情页可显示：

- 磁力。
- 百度、夸克、迅雷、UC、阿里、115、123、天翼、移动云盘。
- PikPak 和光鸭。

插件只负责从 SeedHub 页面取得资源入口并在用户选择后解析最终磁力或网盘分享地址。AList-TVBox 继续负责网盘账号、临时挂载、文件展开、字幕、播放地址和 `client-proxy`。

## 使用流程

```text
首页/分类/搜索
-> 影片详情
-> 选择磁力或网盘分组
-> 选择具体资源
-> 插件解析 /link_start/
-> AList-TVBox /parse 展开文件
-> 选择文件
-> AList-TVBox /play 播放
```

进入详情时不会批量请求数百个 `/link_start/`。只有选择具体资源时才解析，成功结果在当前插件实例内缓存。

## 多域故障转移

插件只使用三个已确认的同站域名：

1. `https://sidhub.cc`
2. `https://seeduck.cc`
3. `https://hubdog.cc`

首页、分类、搜索、详情和资源解析均支持故障转移。某个域名超时、缺少业务标记、跳到非本站域名或返回错误资源类型时，会继续尝试其余镜像；成功域会成为后续首选。

## 资源保护

- 磁力必须包含合法的 32 位 Base32 或 40 位十六进制 BTIH。
- 网盘地址必须使用 HTTPS、受支持域名和有效分享路径。
- 解析结果的提供方必须与详情分组一致，防止百度入口漂移到其他资源。
- 网盘标题必须匹配当前影片中文名或外文名，明显串片会被过滤。
- 标签中的 `#` 和 `$` 会替换，避免破坏 TvBox 选集分隔符。
- 默认每个详情保留 24 个磁力、每种网盘 20 个入口，避免电视端列表过大。

## 配置

插件 EXT 可以留空。需要调整时参照 [extend.example.json](extend.example.json)；字段说明和部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。不要在 EXT 中填写 AList-TVBox 管理员密码、订阅 token、网盘 Cookie 或容器 API 密钥。

## 边界

- 插件不绕过验证码、登录或 WAF 挑战。
- 最终分享是否有效、账号是否已配置以及文件能否播放，以 AList-TVBox `/parse` 和 `/play` 的结果为准。
- 本发布版未做 MuMu 自动操作；客户端焦点、选集点击和实际画面由用户人工验证。
